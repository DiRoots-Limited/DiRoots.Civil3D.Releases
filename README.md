A single application bundle that includes 8 free Civil 3D Plugins to boost your productivity. 
DiCivil provides users, different tools to help design and manage their data to get your job done faster and better.

Tools for Data Management, Filtering, Model Checking, Drawing Production, and Point Clouds.

### Included in DiCivil bundle
- SheetLink
Export your Civil 3D model data (by layers, objects, schedules) to Excel and Google Sheets. Edit the data and import it back to update the model.

- FamilyReviser
Manage your Civil 3D objects (rename, add prefixes and suffixes, and save them in an organized way) and layers (modify layers by category or create your own rules).

- OneFilter
Quickly find and colorize your objects in Civil 3D models. Search by category, parameter name and value. Find objects within Sites, Regions, and Zones.

- TableGen
Import your spreadsheets into Civil 3D as Tables, Schedules, and Drawing Views. Collaborate with non-Civil 3D users and bring your Excel Tables into Civil 3D.

- SheetGen
Create multiple Layouts, place Views based on a pre-defined template, and easily manage Layout revisions. Export and layouts/views lists to/from Excel.

- ReOrdering
Easily renumber instance Civil 3D parameters by using a prefix, a suffix, and a multiplier (manually or following a path/detail line).

- ParaManager
Manage Civil 3D parameters inside project and object environments. Create new parameters, modify existing parameters, export/import parameters to/from Excel and parameter files. Edit parameters in a user-friendly manner (no more Notepad).

- PointKit
Autodesk Civil 3D Add-in to boost your productivity when working with Point Clouds.

- QuickViews
An Autodesk Civil 3D Add-in to easily create Internal Elevation/Section Views and Callouts from Sites/Regions.

- OneParameter
An Autodesk Civil 3D plugin to bulk edit values from Object Properties in your Civil 3D model with a single click.


### Supported Civil 3D Versions
2022, 2023, 2024, 2025, and 2026.
