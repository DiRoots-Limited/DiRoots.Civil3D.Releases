# Subgrade and Base Surfaces

The Earthwork Tool provides capabilities for generating layered surfaces for construction, including subgrade and base surfaces with configurable thicknesses.

## Overview

Subgrade and base surfaces allow you to:
- Generate layered surfaces for construction workflows
- Configure layer thicknesses as needed
- Maintain surface hierarchy and relationships
- Support construction planning and execution
