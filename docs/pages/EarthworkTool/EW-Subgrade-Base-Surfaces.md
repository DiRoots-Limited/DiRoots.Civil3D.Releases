## Creating Subgrade and Base Surfaces

The Earthwork Tool enables you to create multiple subgrade and base surfaces on delimited regions, starting from the proposed surface. This is essential for construction projects with layered pavement or foundation requirements.

### Steps to Create Subgrade/Base Surfaces
1. Select the "Subgrade & Base Surfaces" tab in the Earthwork Tool interface.
2. Choose the proposed surface as the starting point.
3. Define the regions where subgrade/base layers are required.
4. Enter the thickness and material type for each layer.
5. Click "Create Surfaces" to generate the subgrade and base surfaces.

### Usage in Calculations
- The generated subgrade/base surfaces can be used for region-specific cut/fill and material volume calculations.
- The tool reports the total volume for each layer and region.
