# Topsoil Stripping

The Earthwork Tool provides comprehensive topsoil stripping capabilities for creating stripping surfaces with configurable thickness and accurate volume calculations.

## Overview

Topsoil stripping allows you to:
- Create stripping surfaces with configurable thickness
- Calculate stripping volumes accurately
- Plan topsoil removal operations
- Integrate stripping with region-based calculations

## Stripping Surface Creation

### Configurable Thickness

Set stripping depth for each region:

- **Thickness Configuration** - Set stripping depth (e.g., 0.1m, 0.2m)
- **Region-Specific Settings** - Different stripping depths per region
- **Flexible Configuration** - Adjust thickness as needed
- **Validation** - Verify stripping calculations match expected values

> **GIF Placeholder:** Demonstrate configurable thickness

### Stripping Surface Generation

Generate surfaces for topsoil removal:

- **Surface Creation** - Create stripping surfaces automatically
- **Thickness Application** - Apply configured thickness to surfaces
- **Surface Validation** - Validate generated stripping surfaces
- **Quality Control** - Ensure surface quality and accuracy

> **GIF Placeholder:** Show stripping surface generation

Calculate stripping volumes accurately:

- **Stripping Volume** - Calculate volume of topsoil to be removed
- **Region Integration** - Integrate stripping with region calculations
- **Hierarchical Totals** - Include stripping in parent-child relationships
- **Validation** - Verify stripping volume calculations
