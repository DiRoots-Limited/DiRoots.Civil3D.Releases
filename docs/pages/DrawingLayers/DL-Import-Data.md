## Importing Updated Excel Spreadsheets

Drawing Layers provides intelligent import functionality that highlights changes before applying them, ensuring you have full control over what modifications are made to your layer data.

### Import Process
1. **File Selection:** Choose the updated Excel file to import
2. **Change Detection:** The tool automatically compares the imported data with current data
3. **Change Highlighting:** Modified cells are highlighted for easy identification
4. **Review and Confirm:** Review all changes before applying them
5. **Apply Changes:** Confirm and apply the selected modifications

### Change Highlighting Features
- **Modified Values:** Cells with changed data are highlighted in yellow
- **New Entries:** New layers or layer states are highlighted in green
- **Deleted Items:** Items to be removed are highlighted in red
- **Conflict Resolution:** Conflicting changes are highlighted in orange

### Import Options
- **Selective Import:** Choose which changes to apply
- **Batch Import:** Apply all changes at once
- **Conflict Resolution:** Handle conflicts between imported and existing data
- **Validation:** Verify data integrity before importing

### Safety Features
- **Backup Creation:** Automatic backup of current data before import
- **Preview Mode:** Review changes without applying them
- **Rollback Capability:** Undo import operations if needed
- **Validation Checks:** Ensure imported data meets requirements

### Benefits
- Safe and controlled data import process
- Clear visibility of all changes before application
- Conflict detection and resolution
- Maintains data integrity throughout the import process
