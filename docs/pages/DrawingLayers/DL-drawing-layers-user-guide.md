# Drawing Layers User Guide

Learn how to use Drawing Layers to edit layer data and layer states using a spreadsheet-format interface, with Excel export and import capabilities.
{: .fs-6 .fw-300 }

## Description

Drawing Layers provides a powerful spreadsheet-format interface for editing layer data and layer states. The tool allows you to manage your layer and state data efficiently using a familiar spreadsheet interface, complete with formula features, and enables seamless export and import of data to Excel for external editing.

**Key Features:**
- Spreadsheet format interface for direct data editing with formula support
- Export layer and layer states data to Excel for external editing
- Import updated Excel spreadsheets with change highlighting before applying
- Comprehensive layer and layer states management capabilities
