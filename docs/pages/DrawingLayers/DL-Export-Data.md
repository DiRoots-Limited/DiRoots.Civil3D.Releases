# Export Data

Drawing Layers allows you to export your layer data and layer states to Excel format for external editing, enabling collaboration and advanced data manipulation outside the application. The tool provides comprehensive export capabilities for both active layers and layer states.

## Overview

Export functionality enables you to save your layer data to Excel files for external editing, backup, and sharing. The tool supports exporting from both the Active Layers tab and Layer States tab, providing flexibility for different export needs.

## Export Options

### Active Layers Export

Export layer data from the Active Layers tab:

- **Complete Layer Data** - Export all layer properties and settings
- **Used Layers Only** - Export only layers that are currently used
- **Property Selection** - Choose specific properties to export
- **Data Preservation** - Preserve all layer data and properties

### Layer States Export

Export layer state configurations:

- **State Configurations** - Export layer state configurations and assignments
- **State Properties** - Export state properties and settings
- **Layer Assignments** - Export which layers are assigned to each state
- **Complete State Data** - Export complete state information

### Combined Export

Export comprehensive data:

- **Both Tabs** - Export data from both Active Layers and Layer States tabs
- **Separate Worksheets** - Organize data in separate Excel worksheets
- **Complete Export** - Export all available layer and state data
- **Structured Format** - Maintain structured data organization

## Export Process

### Step-by-Step Export

Complete export workflow:

1. **Select Tab** - Choose Active Layers or Layer States tab
2. **Review Data** - Review data to be exported
3. **Export to Excel** - Click "Export to Excel" button
4. **Choose Location** - Select file location and name
5. **Save File** - Save the Excel file with layer data
6. **Verify Export** - Verify exported data is complete

### Export Features

Comprehensive export capabilities:

- **File Format Support** - Support for various Excel formats (.xlsx, .xls, .csv)
- **Data Structure** - Maintain data structure and organization
- **Property Preservation** - Preserve all layer properties and settings
- **Formula Support** - Preserve formulas for calculations and relationships

## Exported Data Structure

### Layer Properties

Comprehensive layer property export:

- **Layer Names** - Layer names and identifiers
- **Color Settings** - Layer colors and color assignments
- **Linetype Properties** - Linetype settings and assignments
- **Lineweight Settings** - Lineweight configurations
- **Plot Style** - Plot style assignments and settings
- **Other Properties** - All other layer properties

### Layer States Data

Complete layer state export:

- **State Names** - Layer state names and identifiers
- **Layer Assignments** - Which layers are assigned to each state
- **Visibility Settings** - On/off, freeze/thaw, lock/unlock settings
- **Color Overrides** - Color override settings for states
- **Linetype Overrides** - Linetype override settings for states
- **Plot Settings** - Print visibility and plot style overrides

### Metadata

Additional export information:

- **Creation Date** - When the export was created
- **Modification Date** - Last modification date
- **User Information** - User who created the export
- **File Information** - Source file information
