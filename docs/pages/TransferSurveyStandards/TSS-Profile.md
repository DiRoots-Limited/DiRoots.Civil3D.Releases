## What's saved in the profile

The following settings are saved in Transfer Survey Standards profiles:
- Transfer source and destination file preferences
- Point Description Keys configurations and mappings
- Figure Prefix Database settings and associations
- Export/import settings and Excel template preferences
- Survey standards data editing preferences and validation rules

## Creating Profiles

Transfer Survey Standards profiles let you save your transfer settings, survey standards configurations, and export/import preferences for reuse and sharing across projects and teams.

Steps:
1. In the window header, click the save button next to the profiles list.
2. Name the profile (choose a meaningful name for easy identification).
3. Choose the location to save it.
4. Click "Save" to store the profile.

## Importing Profiles

Import existing profiles to stay compliant with company standards.

Steps:
1. Click the Import button next to the profiles list.
2. Use File Explorer to find the profile (shared folder, network, or local).
3. Click "Open" to import.

![Transfer Survey Standards importing profiles](../../../assets/images/TransferSurveyStandards/TSS-ImportProfile.gif)
<sub>Note: the version on the image may not reflect the latest version of Transfer Survey Standards.</sub>

## Deleting Profiles

Steps:
1. Select the profile from the dropdown.
2. Click the Delete icon next to the profiles list.
3. Confirm deletion.
