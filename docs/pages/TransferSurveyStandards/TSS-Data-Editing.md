# Data Editing

Transfer Survey Standards provides comprehensive data editing capabilities, allowing you to modify survey standards data directly in the UI before importing to your target file.

## Overview

Data editing allows you to:
- Modify data directly in the UI interface
- Edit data before importing to target file
- Validate modified data before import
- Perform bulk modifications
