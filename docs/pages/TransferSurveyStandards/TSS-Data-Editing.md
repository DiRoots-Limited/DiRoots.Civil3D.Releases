# Data Editing

Transfer Survey Standards provides comprehensive data editing capabilities that allow you to modify Point Description Keys and Figure Prefix Database settings before applying them to files or exporting them to Excel, ensuring complete control over the transfer process.

## Overview

Data editing is a crucial feature that enables you to review and modify survey standards data before applying changes. This includes adding missing columns, modifying values, and ensuring data integrity before transfer or export operations.

## Pre-Transfer Editing

### Comprehensive Data Modification

Edit survey standards settings before applying to target files:

- **Review and Modify** - Edit survey standards settings before applying to target files
- **Bulk Editing** - Modify multiple settings simultaneously
- **Validation** - Validate changes before applying them
- **Preview Changes** - Preview how changes will affect the target files

### Column Management

Add and modify columns as needed:

- **Add Missing Columns** - Add columns that don't exist in imported data
- **Column Modification** - Modify existing columns and their properties
- **Data Structure** - Ensure data structure meets requirements
- **Layer Column Addition** - Add layer columns when missing from source data

### Steps for Data Editing

Complete editing workflow:

1. **Load Data** - Import survey standards from source files or Excel
2. **Review Settings** - Examine current settings and identify areas for modification
3. **Add Columns** - Add missing columns (e.g., layer columns)
4. **Make Changes** - Edit values using the built-in editing interface
5. **Validate Changes** - Verify that all modifications are valid
6. **Apply or Export** - Apply changes to target files or export to Excel

## Workflow Examples

### Example 1: Adding Missing Layer Column

1. **Import Data** - Load data from Excel or source file
2. **Identify Missing Column** - Notice layer column is missing
3. **Add Layer Column** - Add layer column to the data structure
4. **Assign Layers** - Assign appropriate layers to items
5. **Validate Data** - Check that layer assignments are correct
6. **Apply Changes** - Import modified data to target files

### Example 2: Bulk Value Editing

1. **Select Items** - Select multiple items for editing
2. **Choose Property** - Select property to modify
3. **Enter New Value** - Enter new value for selected items
4. **Apply Changes** - Apply changes to all selected items
5. **Validate Results** - Verify changes were applied correctly

### Example 3: Data Structure Modification

1. **Review Structure** - Examine current data structure
2. **Add Columns** - Add required columns
3. **Modify Values** - Edit values in new columns
4. **Validate Structure** - Ensure structure meets requirements
5. **Export or Apply** - Export to Excel or apply to target files

## Best Practices

### Editing Preparation
- **Review Source Data** - Understand source data structure before editing
- **Plan Changes** - Plan modifications before making them
- **Backup Original** - Keep backup of original data
- **Test Changes** - Test modifications on small datasets first

### Data Validation
- **Check Data Integrity** - Verify data is complete and valid
- **Validate Structure** - Ensure data structure meets requirements
- **Test Functionality** - Verify edited data works correctly
- **Document Changes** - Keep records of modifications made

### Quality Control
- **Review Edits** - Carefully review all editing changes
- **Validate Results** - Verify editing results are correct
- **Test Applications** - Test edited data in target applications
- **Error Correction** - Correct any editing errors promptly
