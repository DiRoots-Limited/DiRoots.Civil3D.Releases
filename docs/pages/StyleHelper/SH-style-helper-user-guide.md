# Style Helper User Guide

Learn how to use Style Helper to efficiently edit Civil 3D settings and style data for multiple objects, labels, and tables in a powerful table interface.
{: .fs-6 .fw-300 }

## Description

Style Helper provides a unified table interface to edit multiple Civil 3D object styles, label styles, and table styles at once. The tool mirrors the Civil 3D Tool Space structure and allows you to edit children component data, configure your table columns, and perform bulk edits across multiple objects for maximum productivity.

**Key Features:**
- **Three-Tab Structure** - Object Styles, Label Styles, and Table Styles tabs
- **Civil 3D Integration** - Mirrors Tool Space structure for familiar navigation
- **Object Preferences** - Access and edit data associated with checked objects
- **Column Configuration** - Add, remove, and reorder table columns
- **Parent-Child Relationships** - Edit parent properties that affect multiple components
- **Filtering Capabilities** - Filter data by specific values or criteria
- **Profile System** - Save and reuse column configurations
- **Bulk Editing** - Edit multiple objects and rows simultaneously

## Getting Started

### Main Interface

The Style Helper tool takes a few seconds to load and presents a three-tab interface that mirrors the Civil 3D Tool Space structure:

- **Object Styles Tab** - Access and edit object styles (e.g., Surface Styles)
- **Label Styles Tab** - Access and edit label styles
- **Table Styles Tab** - Access and edit table styles

### Civil 3D Integration

The tool structure corresponds directly to Civil 3D's Tool Space:

- **Settings Comparison** - Compare data with Civil 3D Tool Space Settings
- **Familiar Navigation** - Navigate using the same structure as Civil 3D
- **Data Consistency** - Ensure data consistency between Style Helper and Civil 3D

### Basic Workflow

1. **Open Style Helper** from the DiRoots tab
2. **Select Object Type** - Choose the Civil 3D object type (e.g., Surface)
3. **Check Objects** - Select specific objects to work with
4. **Access Object Preferences** - Load associated data for checked objects
5. **Configure Columns** - Add, remove, or reorder table columns
6. **Edit Data** - Modify style data directly in the table
7. **Save Profile** - Save column configuration for reuse

## Object Styles Management

### Object Selection

Choose Civil 3D objects to work with:

- **Object Type Selection** - Select object types (e.g., Surface, Alignment, Corridor)
- **Object Checking** - Check specific objects within the selected type
- **Data Loading** - Load data associated with checked objects
- **Real-time Updates** - See data updates as objects are checked/unchecked

### Object Preferences

Access comprehensive data for selected objects:

- **Data Association** - View all data associated with checked objects
- **Column Addition** - Add data columns to the table
- **Data Organization** - Organize data in a structured table format
- **Component Data** - Access component-level data for objects

## Column Configuration

### Column Management

Configure table columns to focus on relevant data:

- **Add Columns** - Add data columns from object preferences
- **Remove Columns** - Remove unnecessary columns
- **Reorder Columns** - Change column order using up/down buttons
- **Reset Order** - Reset column order to default

### Column Operations

Efficient column management:

- **Move to Top** - Move columns to the top of the table
- **Move to Bottom** - Move columns to the bottom of the table
- **Custom Order** - Create custom column order for specific workflows
- **Configuration Persistence** - Save column configurations in profiles

## Parent-Child Relationships

### Understanding Relationships

Style Helper displays parent-child relationships clearly:

- **Parent Objects** - Main style objects (e.g., Elevation Binding 2D)
- **Child Components** - Components within parent objects
- **Data Association** - Some data is associated with parent, some with components
- **Inheritance** - Parent properties affect multiple child components

### Editing Parent Properties

Modify properties that affect multiple components:

- **Parent-Level Changes** - Changes to parent properties affect all child components
- **Checkbox Indicators** - Checkboxes show which rows are affected by parent changes
- **Bulk Modifications** - Modify parent properties to update multiple components
- **Visual Feedback** - Clear indication of parent-child relationships
