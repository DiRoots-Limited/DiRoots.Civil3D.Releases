## Simultaneous Multi-Object and Multi-Row Editing

Style Helper enables you to select and edit multiple Civil 3D objects and rows at once, making large-scale changes fast and efficient.

### Steps for Bulk Editing
1. Select the "Bulk Editing" tab in the Style Helper interface.
2. Use the multi-select tool to choose multiple objects or rows in the table.
3. Edit the desired fields; changes will be applied to all selected rows simultaneously.

![Style Helper bulk editing](../../../assets/images/StyleHelper/SH-BulkEditing.gif)
<sub>Note: the version on the image may not reflect the latest version of Style Helper.</sub>

### Supported Bulk Edits
- Object style properties
- Label style properties
- Table style properties
- Children component data

### Benefits
- Make consistent changes across many styles at once
- Save time on repetitive edits
- Reduce the risk of manual errors
