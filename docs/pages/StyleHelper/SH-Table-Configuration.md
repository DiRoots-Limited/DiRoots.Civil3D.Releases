## Configuring and Saving Table Columns

Style Helper allows you to configure which columns are shown in the table interface, their order, and visibility, so you can focus on the data that matters most to you.

### Steps to Configure Table Columns
1. Select the "Table Configuration" tab in the Style Helper interface.
2. Use the column selector to choose which columns to display.
3. Drag and drop columns to reorder them as needed.
4. Adjust column widths and visibility to your preference.
5. Save your table configuration for reuse.

![Style Helper table configuration](../../../assets/images/StyleHelper/SH-TableConfiguration.gif)
<sub>Note: the version on the image may not reflect the latest version of Style Helper.</sub>

### Loading Table Configurations
- Load saved table configurations from your profile or template library.
- Apply different configurations for different workflows or projects.

### Benefits
- Customizable interface for every user
- Save time by focusing only on relevant data
- Easily switch between different table setups
