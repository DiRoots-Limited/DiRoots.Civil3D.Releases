## Editing Children Component Data

Style Helper allows you to view and edit the children component data from styles, such as subcomponents or nested style elements, directly in the table interface.

### Steps to Edit Children Components
1. Select the style(s) you want to edit in the table interface.
2. Expand the row or use the "Show Children" option to display children components.
3. Edit the children component data as needed. Changes are applied in real time.

![Style Helper editing children components](../../../assets/images/StyleHelper/SH-EditChildren.gif)
<sub>Note: the version on the image may not reflect the latest version of Style Helper.</sub>

### Supported Children Components
- Subcomponents of object styles (e.g., display components, linework)
- Nested label style elements
- Table style subcomponents

### Benefits
- Edit all related data in one place
- Maintain consistency across parent and child components
- Quickly update complex style hierarchies
