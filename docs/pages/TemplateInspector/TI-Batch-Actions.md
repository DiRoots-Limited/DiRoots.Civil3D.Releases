# Batch Actions

Template Inspector enables you to perform comprehensive batch operations on multiple objects simultaneously, including object selection, isolation, layer swapping, and deletion. The tool provides efficient batch processing capabilities for managing large numbers of objects.

## Overview

Batch actions allow you to efficiently manage multiple objects at once, saving time and ensuring consistency across operations. The tool supports object selection, isolation, modification, and deletion in batch mode, with comprehensive safety features and confirmation dialogs.

## Object Selection and Management

### Multi-Object Selection

Select and manage multiple objects efficiently:

- **Individual Selection** - Select specific objects from the list
- **Multi-selection** - Select multiple objects using Ctrl+Click or Shift+Click
- **Select All** - Select all objects in the current view
- **Clear Selection** - Clear current selection

### Selection Methods

Different ways to select objects:

- **Single Click** - Select individual objects
- **Ctrl+Click** - Add objects to selection
- **Shift+Click** - Select range of objects
- **Select All** - Select all visible objects

## Object Isolation

### Isolation Features

Isolate objects for focused inspection and management:

- **Isolate Objects** - Show only selected objects
- **End Isolation** - Return to full view
- **Focused Inspection** - Inspect isolated objects in detail
- **Visual Confirmation** - See isolated objects clearly

### Isolation Workflow

Complete isolation process:

1. **Select Objects** - Choose objects to isolate
2. **Isolate Selection** - Click "Isolate Objects" to focus on selection
3. **Inspect Objects** - Examine isolated objects in detail
4. **Perform Actions** - Take actions on isolated objects
5. **End Isolation** - Return to full view when done

### Isolation Benefits

Advantages of object isolation:

- **Focused Work** - Work with specific objects without distraction
- **Clear Visualization** - See isolated objects clearly
- **Efficient Management** - Manage objects more efficiently
- **Reduced Errors** - Reduce errors by focusing on specific objects

## Layer Swapping and Modification

### Layer Assignment Changes

Change layer assignments for objects:

- **Select Target Layer** - Choose the new layer for assignment
- **Update Objects** - Apply layer changes to selected objects
- **Confirmation** - Confirm changes before applying
- **Verification** - Check that changes were applied correctly

### Layer Swapping Process

Complete layer swapping workflow:

1. **Select Objects** - Choose objects to modify
2. **Choose New Layer** - Select target layer for assignment
3. **Update Objects** - Apply layer changes
4. **Confirm Changes** - Verify changes were applied
5. **Check Results** - Verify objects now use new layer

### Example Layer Swapping

Practical layer swapping example:
- **Select Objects** - Choose objects currently on one layer
- **Choose "Road Corridor"** - Select "Road Corridor" as new layer
- **Update Objects** - Apply layer change to selected objects
- **Confirmation** - System confirms all changes were applied
- **Verification** - Check that objects now use "Road Corridor" layer

## Batch Updates

### Multi-Object Updates

Update multiple objects simultaneously:

- **Batch Selection** - Select multiple objects for batch operations
- **Batch Updates** - Apply changes to all selected objects
- **Confirmation** - Confirm batch operations before applying
- **Progress Tracking** - Monitor batch operation progress

### Batch Modification Workflow

Complete batch modification process:

1. **Select Objects** - Choose multiple objects to modify
2. **Choose Action** - Select the modification to apply
3. **Configure Settings** - Set up modification parameters
4. **Apply Changes** - Execute batch modification
5. **Verify Results** - Check that all changes were applied

### Batch Operation Types

Different types of batch operations:

#### Layer Operations
- **Batch Layer Assignment** - Assign multiple objects to a new layer
- **Layer Swapping** - Swap layer assignments for multiple objects
- **Layer Cleanup** - Clean up layer assignments

#### Style Operations
- **Style Assignment** - Assign styles to multiple objects
- **Style Swapping** - Swap styles for multiple objects
- **Style Cleanup** - Clean up style assignments

## Object Deletion

### Safe Deletion Process

Delete unused objects safely:

- **Unused Object Detection** - Identify objects that are not used
- **Deletion Confirmation** - Confirm deletion before proceeding
- **Safety Checks** - Verify objects can be safely deleted
- **Backup Recommendations** - Suggest backups for important operations

### Deletion Workflow

Safe object deletion process:

1. **Identify Unused Objects** - Find objects that are not referenced
2. **Review Dependencies** - Check for any hidden dependencies
3. **Confirm Deletion** - Confirm deletion action
4. **Execute Deletion** - Remove unused objects
5. **Verify Cleanup** - Confirm objects were removed

### Deletion Safety Features

Safety measures for object deletion:

- **Confirmation Dialogs** - Require confirmation for deletion
- **Dependency Checks** - Check for dependencies before deletion
- **Usage Verification** - Verify objects are truly unused
- **Backup Suggestions** - Suggest backups for important data
