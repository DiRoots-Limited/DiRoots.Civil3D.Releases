# Transfer Object Layers User Guide

Learn how to use Transfer Object Layers to transfer Civil 3D object layer settings between projects while preserving all properties and layers, with Excel export and import capabilities.
{: .fs-6 .fw-300 }

## Description

Transfer Object Layers helps you transfer your Civil 3D object layer settings between projects while preserving all properties and layers. The tool simplifies the process with batch transfer capabilities, all while maintaining your layer data. Whether you're standardizing content, setting up new projects, or enforcing standards, this tool provides efficient transfer solutions with Excel export and import functionality.

**Key Features:**
- Transfer object layer settings from open or closed Civil 3D files
- Export and import Civil 3D object layer data to structured Excel templates
- Edit values before setting them in files or before exporting
- Batch transfer capabilities for multiple projects
