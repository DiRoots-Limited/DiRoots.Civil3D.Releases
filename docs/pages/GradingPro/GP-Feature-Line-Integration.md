## Including Feature Lines in Section Definitions

Grading Pro allows you to include feature lines as objects in your section definitions, providing greater control and flexibility in grading design.

### Steps to Integrate Feature Lines
1. Select the "Feature Line Integration" tab in the Grading Pro interface.
2. Choose the feature lines to include in your section definition.
3. Assign roles to each feature line (e.g., boundary, breakline, reference).
4. Incorporate the feature lines into your section configuration.

![Grading Pro feature line integration](../../../assets/images/GradingPro/GP-FeatureLineIntegration.gif)
<sub>Note: the version on the image may not reflect the latest version of Grading Pro.</sub>

### Impact on Grading Design
- Feature lines can define section boundaries, control grading slopes, and ensure design intent is maintained.
- Modifying feature lines automatically updates associated sections and surfaces.
- Supports complex grading scenarios with multiple interacting feature lines.
