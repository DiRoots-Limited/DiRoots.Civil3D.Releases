## Configuring and Reusing Sections

Grading Pro allows you to configure grading sections using multiple methods and reuse these configurations across different projects, saving time and ensuring consistency.

### Section Configuration Methods
- **Manual definition:** Draw or specify section geometry directly.
- **Template-based:** Use predefined templates for common grading scenarios.
- **Reference-based:** Position sections from a reference line or point.
- **Feature line-based:** Use feature lines to define section boundaries or geometry.

### Steps to Configure a Section
1. Select the "Section Configuration" tab in the Grading Pro interface.
2. Choose your preferred method for defining the section.
3. Enter or select the required parameters (geometry, reference, feature lines, etc.).
4. Save the section configuration for reuse.

### Reusing Section Configurations
- Load saved section configurations from your profile or template library.
- Apply the configuration to new projects or different areas within the same project.
- Edit and resave configurations as needed for future use.
