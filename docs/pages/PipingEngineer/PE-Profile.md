## What's saved in the profile

The following settings are saved in the Piping Engineer profiles.

- Piping system selection (by network, specific elements, or start/end points)
- Pipes and Structures tables configuration
- Selected properties and parameters for editing
- Elevation design settings and references
- Slope validation rules and overrides
- Network validation preferences

## Creating Profiles

Piping Engineer profiles make it easy to save your piping design settings and reuse them later. It is also a handy way for BIM Managers to create standard rules for piping network design and share them across the organization.

Steps:
1. In the window header, click on the save button next to the profiles list.
2. Name the profile (give it a meaningful name because this is the name that will show up in the profiles list)
3. Choose the location to save it.
4. Click on the "Save" button to save the profile.

## Importing Profiles

Piping Engineer profiles make it easy to import existing profiles to stay compliant with your company standards (e.g., profiles in a network location).

Steps:
1. In the window header, click on the Import button next to the profiles list.
2. Use the Windows File Explorer to find the profile (e.g., in a shared folder, location network, or local computer)
3. Click on the "Open" button to import the profile.

## Deleting Profiles

Steps:
1. In the window header, select the from the dropdown the profile you want to delete
2. Click on the Delete icon next to the profiles list.
3. Confirm.
