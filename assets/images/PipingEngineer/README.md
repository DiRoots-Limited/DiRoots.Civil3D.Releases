## Image Specifications

- **GIFs**: For animated demonstrations of features
- **PNGs**: For static screenshots and UI elements
- **Resolution**: Minimum 1280x720 for clarity
- **File Size**: Optimize for web delivery (under 2MB for GIFs, under 500KB for PNGs)

## Notes

- All images should be captured from the latest version of Piping Engineer
- Include version disclaimers in documentation when images may not reflect current version
- Maintain consistent UI styling and color schemes across all images
